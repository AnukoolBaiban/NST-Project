# NST-Project: การวิเคราะห์สังคมจุลินทรีย์ในดิน (Microbiome Analysis)

โปรเจกต์นี้ใช้สำหรับวิเคราะห์และสร้างภาพข้อมูล (Visualization) ของสังคมจุลินทรีย์ในดิน เพื่อเปรียบเทียบความแตกต่างระหว่างฟาร์มแบบ **เกษตรอินทรีย์ (Organic)** และ **เกษตรเคมี (Chemical)** โดยใช้ข้อมูลจาก 16S rRNA Sequencing

## 📋 รายละเอียดโปรเจกต์
โปรแกรมนี้จะประมวลผลข้อมูลดิบจากตาราง Feature Table และผลการวิเคราะห์ LEfSe เพื่อสร้างกราฟ 3 รูปแบบที่ช่วยในการระบุตัวบ่งชี้ทางชีวภาพ (Biomarkers) และรูปแบบการกระจายตัวของจุลินทรีย์

### กราฟที่สร้างขึ้น:
1. **LEfSe Bar Plot**: แสดงค่า LDA Score เพื่อระบุจุลินทรีย์ที่เป็นตัวแทนของแต่ละกลุ่มฟาร์ม
2. **Clustered Heatmap**: แสดงแพทเทิร์นความชุกของจุลินทรีย์และการจัดกลุ่มของตัวอย่าง (Sample Clustering)
3. **Bubble Plot**: แสดงความชุกสัมพัทธ์ (Relative Abundance) โดยใช้ขนาดของฟองสบู่เพื่อให้เห็นจุลินทรีย์กลุ่มเด่น (Dominant Taxa) ได้ชัดเจน
