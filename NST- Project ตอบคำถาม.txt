NST- Project ตอบคำถาม
================================================================
ข้อ 1
เลือก taxonomic rank และ LDA cut-off และ %relative abundance ที่คิดว่าสามารถแสดงให้เห็น
pattern ความแตกต่างของจุลินทรีย์ระหว่างฟาร์มสองประเภทได้มากที่สุด (Organic/Chemical)
พร้อมอธิบาย pattern ที่แตกต่าง และให้เหตุผลการเลือก taxonomic rank และ cut-off
================================================================

─── ค่าพารามิเตอร์ที่เลือก ───
  • Taxonomic Rank  : Genus ('g') พร้อมระบบ Fallback
  • LDA Score       : ≥ 3.0
  • Rel. Abundance  : ≥ 0.1%
  • p-value         : ≤ 0.05

─── เหตุผลการเลือก ───

[Taxonomic Rank — Genus + Fallback]
Genus เป็นระดับที่ให้ความละเอียดทางชีวภาพสูงสุด ช่วยระบุชนิดจุลินทรีย์ที่มีหน้าที่เฉพาะใน
ระบบนิเวศดินได้ชัดเจนกว่าระดับ Phylum หรือ Class ระบบ Fallback ช่วยป้องกันการสูญเสียข้อมูล
ในกรณีที่ระบุ Genus ไม่ได้ โดยถอยกลับไปใช้ระดับที่สูงกว่า (Family → Order → Class → Phylum)
พร้อมระบุระดับนั้นในชื่อ เช่น Gaiellales (o)

[LDA Score Cut-off — 3.0]
LDA = 3.0 คัดเฉพาะจุลินทรีย์ที่มี Effect Size สูง คือมีความแตกต่างระหว่างกลุ่มอย่างรุนแรงและ
ชัดเจน ช่วยตัด Noise จากจุลินทรีย์ที่ต่างกันเพียงเล็กน้อยออกไป ผลที่ได้คือ Significant Taxa รวม
56 ชนิด (Organic 39 ชนิด / Chemical 17 ชนิด) ซึ่งเป็นจำนวนที่เหมาะสมต่อการสื่อสารด้วยกราฟ

[% Relative Abundance Cut-off — 0.1%]
กรอง Rare taxa ที่มักไม่มีบทบาทสำคัญต่อโครงสร้างสังคมจุลินทรีย์โดยรวมออกไป ทำให้กราฟ
Bubble Plot และ Heatmap ดูสะอาดตา และมุ่งเน้นไปที่กลุ่มที่ขับเคลื่อนความแตกต่างของดินจริงๆ

─── รูปแบบความแตกต่าง (Pattern) ที่พบ ───

[Pattern 1 — Distinct Clustering]
ในกราฟ Heatmap ตัวอย่างฟาร์ม Organic และ Chemical ถูกจัดกลุ่มแยกออกจากกันอย่างชัดเจน
ตาม Dendrogram แสดงให้เห็นว่าแนวทางการทำฟาร์มที่ต่างกันส่งผลให้สังคมจุลินทรีย์เปลี่ยนแปลง
อย่างมีนัยสำคัญ

[Pattern 2 — Mutual Exclusion]
จุลินทรีย์บางชนิดพบมากในฟาร์มประเภทหนึ่งแต่แทบหายไปในอีกประเภทหนึ่ง:

  • Organic (39 ชนิด) — ตัวบ่งชี้หลักที่ LDA สูงสุด:
      Gaiellales (o)         LDA = 4.920
      TK10 (c)               LDA = 4.575
      Vicinamibacterales (o) LDA = 4.516
      Gaiella                LDA = 4.367
      Roseiflexaceae (f)     LDA = 4.302
      Nitrososphaeraceae (f) LDA = 4.140

  • Chemical (17 ชนิด) — ตัวบ่งชี้หลักที่ LDA สูงสุด:
      Frankiales (o)         LDA = 5.077
      Acidothermus           LDA = 5.049
      Elsterales (o)         LDA = 4.905
      Nitrosotaleaceae (f)   LDA = 4.716
      Subgroup_2 (o)         LDA = 4.663
      Alicyclobacillus       LDA = 4.223

[Pattern 3 — Visual Consistency]
รูปแบบเดียวกันปรากฏสอดคล้องกันทั้ง 3 กราฟ — Bubble Plot แสดงฟองขนาดใหญ่กระจุกตัวเฉพาะ
กลุ่มใดกลุ่มหนึ่ง / LEfSe Plot ยืนยันนัยสำคัญทางสถิติ / Heatmap แสดง Clustering ที่ชัดเจน



================================================================
ข้อ 2
จาก taxonomic rank และ cut-off ที่เลือก แสดงความเห็นว่ากราฟชนิดใดที่แสดงให้เห็น
dominant taxa (จุลินทรีย์ที่มี abundance มาก) ได้ดีที่สุด เพราะอะไร
================================================================

คำตอบ: Bubble Plot แสดง Dominant Taxa ได้ดีที่สุด

[เหตุผลที่ 1 — Visual Encoding of Size]
Bubble Plot ใช้ขนาดของวงกลมแทนค่า % Relative Abundance โดยตรง สายตามนุษย์สามารถ
เปรียบเทียบขนาดวงกลมได้ง่ายและรวดเร็วกว่าการแปลระดับสีหรือความยาวแท่ง วงกลมที่ใหญ่ที่สุด
จะดึงดูดสายตาทันที ทำให้ระบุ Dominant Taxa ได้โดยไม่ต้องอาศัยค่าตัวเลข

[เหตุผลที่ 2 — Sample-specific Abundance]
Bubble Plot แสดงฟองแยกตาม Sample ทำให้เห็นได้ว่า Dominant Taxa นั้นเด่นสม่ำเสมอใน
ทุกตัวอย่างภายในกลุ่ม หรือเด่นเฉพาะบางฟาร์ม ซึ่ง Heatmap และ LEfSe Plot ไม่ได้ให้ข้อมูล
ในมิตินี้โดยตรง

[ข้อจำกัดของกราฟชนิดอื่น]
  • Heatmap    : แสดงด้วยความเข้มของสี ซึ่งแยกแยะระดับได้ยากกว่าขนาดวงกลม
                เหมาะกับการดู Clustering Pattern มากกว่าการระบุ Dominant Taxa
  • LEfSe Plot : เน้นแสดง Effect Size (LDA Score) ไม่ใช่ปริมาณโดยตรง จุลินทรีย์ที่มี
                LDA สูงอาจมี Abundance รวมต่ำมากก็ได้ จึงไม่เหมาะกับการดู Dominant Taxa

สรุป: Bubble Plot แสดง Dominant Taxa ได้ดีที่สุด เพราะขนาดฟองแปรผันตรงกับค่า
% Relative Abundance — วงกลมยิ่งใหญ่ ยิ่งมีปริมาณมาก = Dominant Taxa



================================================================
ข้อ 3
จากผลการ visualize จุลินทรีย์ชนิดใดบ้างที่มีความแตกต่างและน่าสนใจระหว่างฟาร์มแต่ละประเภท
(Organic/Chemical) อธิบายเหตุผล
================================================================

จากผลการวิเคราะห์ (Genus, LDA ≥ 3.0, Abundance ≥ 0.1%) พบ Significant Taxa รวม 56 ชนิด
แบ่งเป็น Organic 39 ชนิด และ Chemical 17 ชนิด จุลินทรีย์ที่น่าสนใจมีดังนี้

─── กลุ่มที่ 1: ตัวบ่งชี้ฟาร์ม Organic ───

[Gaiellales (o) และ Gaiella] น่าสนใจที่สุดในกลุ่ม Organic
  LDA Score : Gaiellales (o) = 4.920 (สูงสุดในฝั่ง Organic) / Gaiella = 4.367
  Abundance : Gaiella — Organic 2.33% vs Chemical 0.41% (Fold Change 5.70×)
  เหตุผล   : Gaiellales เกี่ยวข้องกับวัฏจักรคาร์บอนและไนโตรเจนในดิน มักพบในดินที่มีความ
              สมบูรณ์สูงและไม่ถูกรบกวนโดยสารเคมี การที่ Gaiellales และ Gaiella เด่นชัดใน
              ฟาร์ม Organic จึงเป็นตัวบ่งชี้สภาพดินที่มีสุขภาพดีและมีความหลากหลายทางชีวภาพ

[Nitrososphaeraceae (f) และ Candidatus_Nitrosocosmicus]
  LDA Score : Nitrososphaeraceae (f) = 4.140
  Abundance : Nitrososphaeraceae — Fold Change 5.77× (Organic มากกว่า)
              Candidatus_Nitrosocosmicus — Fold Change 10.98× (Organic มากกว่า)
  เหตุผล   : เป็นกลุ่ม Ammonia-Oxidizing Archaea (AOA) ที่ทำหน้าที่ออกซิไดซ์แอมโมเนียม
              ในวัฏจักรไนโตรเจนตามธรรมชาติ การพบมากในดิน Organic แสดงให้เห็นว่าดิน
              ประเภทนี้มีกิจกรรมวัฏจักรไนโตรเจนเชิงชีววิทยาสูงกว่า ตรงข้ามกับดิน Chemical
              ที่พึ่งพาไนโตรเจนจากปุ๋ยเคมี

[Vicinamibacterales (o) และ Candidatus_Udaeobacter]
  LDA Score : Vicinamibacterales (o) = 4.516 / Candidatus_Udaeobacter = 3.952
  Abundance : Vicinamibacterales — Organic 3.28% vs Chemical 1.10% (Fold Change 2.99×)
              Candidatus_Udaeobacter — Fold Change 5.46× (Organic มากกว่า)
  เหตุผล   : Vicinamibacterales ไวต่อสารเคมีสังเคราะห์ ส่วน Candidatus_Udaeobacter
              พบมากในดินที่มีอินทรียวัตถุสูง ทั้งสองชนิดยืนยันความแตกต่างของคุณภาพดิน
              ระหว่างระบบการทำฟาร์มทั้งสอง

─── กลุ่มที่ 2: ตัวบ่งชี้ฟาร์ม Chemical ───

[Frankiales (o) และ Acidothermus] น่าสนใจที่สุดในกลุ่ม Chemical
  LDA Score : Frankiales (o) = 5.077 (สูงสุดในฝั่ง Chemical) / Acidothermus = 5.049
              (Acidothermus มี LDA สูงสุดในการวิเคราะห์ทั้งหมด)
  Abundance : Acidothermus — Chemical 11.20% vs Organic 4.45% (Chemical มากกว่า ~2.5×)
  เหตุผล   : Acidothermus เป็น Acidothermophilic bacteria ที่เจริญได้ดีในสภาวะกรด–อุณหภูมิสูง
              การพบมากใน Chemical สะท้อนถึงดินที่มีความเป็นกรดสูงขึ้นจากการใช้ปุ๋ยเคมี
              ต่อเนื่อง แม้ Frankiales ปกติมีบทบาทตรึงไนโตรเจน แต่การเด่นในฟาร์ม Chemical
              อาจสะท้อนการปรับตัวต่อระดับไนโตรเจนสูงจากปุ๋ยเคมี

[Nitrosotaleaceae (f)]
  LDA Score : 4.716
  Abundance : Chemical 5.20% vs Organic 0.02% (ต่างกันอย่างท่วมท้น)
  เหตุผล   : เป็น Ammonia-Oxidizing Archaea ที่เจริญได้ดีในสภาวะดินกรด ซึ่งตรงข้ามกับ
              Nitrososphaeraceae (Organic) คู่ตรงข้าม Nitrosotaleaceae (Chemical) vs
              Nitrososphaeraceae (Organic) นี้เป็นหลักฐานชัดเจนว่าวัฏจักรไนโตรเจนในดิน
              ทั้งสองประเภทถูกควบคุมโดยชุมชนจุลินทรีย์ที่แตกต่างกันโดยสิ้นเชิง

[Alicyclobacillus และ Acidibacter]
  LDA Score : Alicyclobacillus = 4.223 / Acidibacter = 4.225
  Abundance : Alicyclobacillus — Chemical 1.67% vs Organic 0.00% (พบเฉพาะใน Chemical)
              Acidibacter — Chemical มากกว่า Organic ~4.6×
  เหตุผล   : ทั้งสองชนิดเป็นจุลินทรีย์ที่ชอบสภาวะกรด (Acidophilic) การที่พบมากใน Chemical
              และแทบไม่พบใน Organic แสดงให้เห็นถึงความแตกต่างของค่า pH ดินระหว่างฟาร์ม
              ทั้งสองประเภทอย่างชัดเจน


จุลินทรีย์เหล่านี้ไม่ได้แค่มีปริมาณต่างกัน แต่มีรูปแบบการกระจายตัวแบบ "Near-Exclusive"
(พบมากในฝั่งใดฝั่งหนึ่งอย่างท่วมท้น) โดยเฉพาะคู่ที่เกี่ยวกับวัฏจักรไนโตรเจน
(Nitrososphaeraceae vs Nitrosotaleaceae) และกลุ่มที่ชี้ระดับความเป็นกรดของดิน
(Acidothermus, Alicyclobacillus, Acidibacter) ซึ่งแสดงให้เห็นว่าการเลือกระบบการทำฟาร์ม
(Organic vs Chemical) ส่งผลกระทบอย่างรุนแรงต่อการคัดเลือกชนิดจุลินทรีย์ในดิน
จุลินทรีย์กลุ่มที่ระบุข้างต้นจึงสามารถใช้เป็น Bio-indicators ดัชนีชี้วัดประเภทและสุขภาพของดิน
ในพื้นที่นั้นๆ ได้อย่างแม่นยำ
